🚀 QUICK START (3 COMMANDS):
═══════════════════════════════════════════════════════════════════════════════

1. Install Dependencies:
   pip install -r requirements.txt

2. Start PostgreSQL (if using Docker):
   docker run --name vaultline-db -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres:15

3. Start the Server:
   uvicorn app.main:app --reload

🔐 SECURITY MODEL:
═══════════════════════════════════════════════════════════════════════════════

ZERO-KNOWLEDGE ENCRYPTION:
  Client encrypts → Server stores ciphertext
  Server NEVER sees: plaintext, filenames, encryption keys

PASSWORD SECURITY:
  User Password → PBKDF2 (600k iterations) → authProof
  authProof → bcrypt (12 rounds) → hashed_auth_proof
  Result: Double security layer

FILE SHARING:
  Same file, different wrapped keys
  No re-encryption needed
  Efficient sharing at scale
